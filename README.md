<h2 align="center">✦ O projeto</h2>

<p align="center">
    A <strong>Auréa Joias</strong> é uma marca fictícia criada para este case de<br />
    UI/UX Design e desenvolvimento front-end.
</p>

<p align="center">
    A proposta foi construir uma vitrine digital com atmosfera editorial,<br />
    valorizando os detalhes das peças e a identidade de quem as usa.
</p>

<h2 align="center">✦ Executando o projeto</h2>

<details>
<summary><strong>Ver instruções</strong></summary>

<br />

Clone o repositório:

git clone https://github.com/evellynmayarax/aurea-joias.git

Entre na pasta:

cd aurea-joias

Instale as dependências:

npm install

Inicie o ambiente de desenvolvimento:

npm run dev

Para acessar pela rede local:

npm run dev -- --host

Gere o build de produção:

npm run build

</details>
